# react-microplate

A React component for rendering microplates (96/384-well plates).

## Install

```sh
npm install react-microplate
```

## Usage

```tsx
import { Microplate } from 'react-microplate';

function App() {
  return <Microplate />;
}
```

## Development

```sh
npm install
npm run storybook   # develop components in isolation
npm test            # run the Jest test suite
npm run build        # build the distributable package to dist/
```
